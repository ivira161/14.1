# Магазин продуктов на Python

Это проект на Python, реализующий систему управления продуктами и категориями. Продукты могут быть разного типа (например, смартфоны, газонная трава), а категории объединяют их с различными проверками на корректность.

---

##  **Особенности проекта**
- Управление продуктами через класс `Product` и его наследников (`Smartphone`, `LawnGrass`).
- Добавление продуктов в категории с проверками типа.
- Расчёт общего количества продуктов и обновление данных в категориях.
- Поддержка сложения продуктов через магический метод `__add__`.
- Валидация данных при создании продуктов и добавлении их в категории.

---
## 🛠 **Требования**
- Python 3.8+
- Зависимости проекта указаны в `pyproject.toml` или `requirements.txt`.

Для установки необходимых библиотек:

`pip install -r requirements.txt`

## ⚙️ Основные классы
### 🛒 Класс Product
Основной класс для продуктов с базовыми атрибутами:

name: название продукта
description: описание
price: цена продукта
quantity: количество

### 📱 Класс Smartphone (наследник Product)
Расширяет функциональность Product и добавляет дополнительные атрибуты:

efficiency: производительность
model: модель
memory: объём памяти
color: цвет

### 🌱 Класс LawnGrass (наследник Product)
Класс для газонной травы с дополнительными атрибутами:

country: страна-производитель
germination_period: срок прорастания
color: цвет

### 🗂️ Класс Category
Класс предназначен для группировки продуктов в логические категории. Поддерживает добавление, удаление продуктов и подсчёт общего количества продуктов.

🔍 Основные проверки:

Проверяет, что добавляемые объекты являются экземплярами класса Product 
или его наследников с помощью isinstance().
🔧 Основные методы:

- add_product(product: Product): Добавляет продукт в категорию.
- remove_product(product: Product): Удаляет продукт из категории.
- products_list: Возвращает список объектов продуктов в категории.
- products: Возвращает строковое представление всех продуктов в категории.
